class=\"w-richtext\"><p>Plotting lines on maps in Power BI with the default map visuals is impossible. A typical map where you plot out some spatial data looks like below.</p><figure style=\"max-width:1024px\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/points-map-1024x753.png\" loading=\"lazy\" alt=\"\"/></div></figure><p>Luckily, ESRI have integrated their powerful ArcGIS map into Power BI but few Power BI developers are aware of what possibilites this opens up.</p><p>ArcGIS is a very powerful spatial representation tool. I do not have the expertise to go through all the details of product. There is such a thing as a GIS developer and these people work with spatial data and visualizations all the time. I&#x27;m not one of them. You can check out the <a href=\"https://www.esri.com/en-us/home\" target=\"_blank\">ESRI website</a> for more details.</p><p>One of the most powerful features of ArcGIS, and the one that we&#x27;ll use to solve our problem, is that you can create your own map layers. For this, you need to use ESRI&#x27;s <a href=\"https://www.esri.com/en-us/arcgis/products/arcgis-online/overview\" target=\"_blank\">ArcGIS Online</a>.</p><p>So let&#x27;s dive in and see a step-by-step short walkthrough of how to use ArcGIS to add lines on maps and use them in Power BI as in the gif below.</p><p>‍</p><figure style=\"max-width:969px\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/correct-gif-arcgis.gif\" loading=\"lazy\" alt=\"\"/></div></figure></div></div></div></div><div class=\"cs-grassroot-wrapper\"><div class=\"cs-grassroot-content\"><div id=\"w-node-_1b997da7-60ee-867b-7d8e-b89d1cace6f5-e2700037\" class=\"gv-richt-text\"><div class=\"w-richtext\"><figure style=\"max-width:927pxpx\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/Screenshot-2020-11-28-165735-1.png\" loading=\"lazy\" alt=\"\"/></div></figure><p>‍</p><p>PowerBI has quite a few mapping options for visualizing spatial data. It can work with latitudes, longitudes, country, city, street names, zip codes.</p><p>There are currently 5 standard map visualizations available in PowerBI, including the rather new Azure map. </p><figure class=\"w-richtext-align-center w-richtext-figure-type-image\"><div><img src=\"./images/map-options3.jpg\" loading=\"lazy\" alt=\"\"/></div></figure><p>Add to these a few other community maps and whatever maps you can create in D3, R or Python and you’ve got a pretty good selection of maps for your geographic data.</p><p>Still, there are a few limitations with the current options – unless you heavily code your custom maps. One of which is the inability to map polylines or linestrings, as they are called, in GeoJSON files.<br/>GeoJSON files geometry types are: <em>Point, LineString, Polygon, MultiPoint, MultiLineString, and MultiPolygon – </em><a href=\"https://geojson.org/\"><em>https://geojson.org/</em></a><em>.</em></p><p>Mapping points and polygons are fairly easy with the standard maps and community maps.</p><figure style=\"max-width:1051pxpx\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/points-map.png\" loading=\"lazy\" alt=\"\"/></div></figure><p>‍</p><p>Mapping linestrings is not as straightforward and linestrings are really the only correct way of visualizing some geographic data like driving routes or street parking spaces.</p><p>We recently worked on a project where we needed to map out parking spaces. We explored our no-code options. The first one was the Azure map. We managed to create this map below. How did we do it? We just added the geojson dataset as a reference layer which mapped out the lines in that sky-blue color.</p><p>The reference layer is boring, though. It’s just…well…a reference layer. You cannot interact with it, you can’t color it by a legend and you can’t cross-filter it with from slicers or other charts. It’s just a static, albeit correctly charted, image on your map.</p><p>‍</p><figure style=\"max-width:1365pxpx\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/azure-map.png\" loading=\"lazy\" alt=\"\"/></div></figure><p>After more investigation and still wanting to go no-code we landed on ESRI’s ArcGIS online service. After creating a trial account and fiddling around we managed to create a reference layer that we could customize to our needs. We then realized we had to publish the layer publicly on ArcGIS so we could then import it as a reference layer in PowerBI.</p><p>‍</p><figure style=\"max-width:1200pxpx\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/correct-gif.gif\" loading=\"lazy\" alt=\"\"/></div></figure><p>‍</p><figure style=\"max-width:1060pxpx\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/arcgis-powerbi.png\" loading=\"lazy\" alt=\"\"/></div></figure><p>Like that, we managed to create a better, richer reference layer that:</p><ul role=\"list\"><li>showed parking capacities by types;</li><li>calculated the length of each shape;</li><li>you could interact with – click on each shape and see its properties.</li></ul><p><br/>The current limitations we found are as follows:</p><ul role=\"list\"><li>the reference layer still doesn’t interact with other slicers and charts on the page. As far as I understand, the reference layer comes from ArcGIS with its internal dataset that, obviously, doesn’t communicate with your dataset in PowerBI;</li><li>on the layer pane, you can’t click on the different categories to highlight or filter them on the map;</li><li>you can’t add multiple custom layers on the same map;</li><li>you need a paid ArcGIS account to use ArcGIS maps in production in Power BI.</li></ul><p>This is surely better than nothing, but it still leaves a lot to want. So the search for lines on maps continues and it might be that the only robust option right now is the one you code yourself.</p><figure style=\"max-width:969pxpx\" class=\"w-richtext-align-fullwidth w-richtext-figure-type-image\"><div><img src=\"./images/correct-gif-arcgis.gif\" loading=\"lazy\" alt=\"\"/></div></figure></div></div><div class=\"scroll-overlay grassroot\"></div></div></div>"} />
